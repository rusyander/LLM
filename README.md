# HADA - Hybrid Autonomous Development Agent

**Гибридный автономный агент разработки** с поддержкой локальных LLM и облачной помощи.

## 🎯 Особенности

- **🤖 Гибридная архитектура**: Локальные модели для выполнения + Claude для архитектуры и ревью
- **💬 Многостраничные чаты**: Каждая тема в отдельном чате с изолированным контекстом
- **🧠 Умное управление контекстом**: Автоматическое создание сводок беседы
- **🎤 Голосовой ввод**: Встроенное распознавание речи на русском языке
- **📦 Агентная система**: Архитектор, исполнитель и ревьюер работают совместно
- **🔒 Local-first**: Полная работа в локальном режиме без облака

## 📋 Требования

- **Node.js** >= 18.0.0
- **Ollama** (для локальных моделей)
- **Git**
- **Windows 11** (основная платформа)

## 🚀 Установка

### 1. Установка Ollama и моделей

```bash
# Установите Ollama с официального сайта: https://ollama.ai

# Загрузите Qwen3
ollama pull qwen3:latest
```

### 2. Клонирование и установка зависимостей

```bash
cd d:\Work\LLM
npm install
```

### 3. Настройка окружения

Создайте файл `.env` на основе `.env.example`:

```env
# Ключ Anthropic (необязательно для локального режима)
ANTHROPIC_API_KEY=your_api_key_here

# Настройки локальных LLM
LOCAL_LLM_PROVIDER=ollama
LOCAL_LLM_HOST=http://localhost:11434
DEFAULT_EXECUTOR_MODEL=qwen3

# Режим работы: local_only | hybrid
AGENT_MODE=hybrid

# Порт сервера
PORT=3001
```

### 4. Запуск

```bash
# Режим разработки (запустит и фронтенд, и бэкенд)
npm run dev

# Или отдельно:
npm run server  # Бэкенд на порту 3001
npm run client  # Фронтенд на порту 5173
```

Откройте браузер: **http://localhost:5173**

## 🎮 Использование

### Базовые операции

1. **Создание нового чата**
   - Нажмите "+ Новый чат" в сайдбаре
   - Каждый чат имеет изолированный контекст

2. **Отправка сообщения**
   - Введите текст в поле ввода
   - Нажмите Enter или кнопку отправки
   - Shift+Enter для новой строки

3. **Голосовой ввод**
   - Нажмите кнопку микрофона 🎤
   - Говорите на русском языке
   - Нажмите галочку ✓ для завершения
   - Можно добавлять несколько голосовых фрагментов

4. **Управление контекстом**
   - Откройте настройки (⚙️)
   - "Очистить контекст этого чата" - сброс текущего
   - "Очистить все контексты" - полный сброс

### Режимы работы

#### Локальный режим (`local_only`)

```env
AGENT_MODE=local_only
```

- Работает только с Qwen3 через Ollama
- Не требует интернета
- Быстрая генерация кода
- Подходит для простых задач

#### Гибридный режим (`hybrid`)

```env
AGENT_MODE=hybrid
ANTHROPIC_API_KEY=sk-...
```

- Claude анализирует и создает план
- Qwen3 выполняет задачи
- Claude проверяет результаты
- Высокое качество для сложных проектов

## 📊 API Endpoints

### Чаты

- `GET /api/chats` - Список всех чатов
- `POST /api/chats` - Создать новый чат
- `GET /api/chats/:id` - Получить чат
- `DELETE /api/chats/:id` - Удалить чат

### Сообщения

- `GET /api/chats/:id/messages` - Все сообщения чата
- `POST /api/chats/:id/messages` - Отправить сообщение

### Контекст

- `GET /api/chats/:id/context` - Получить контекст чата
- `DELETE /api/chats/:id/context` - Очистить контекст чата
- `DELETE /api/context/all` - Очистить все контексты

### Система

- `GET /api/health` - Статус сервисов
- `GET /api/config` - Конфигурация приложения

## 🐛 Решение проблем

### Ollama не подключается

```bash
# Проверьте статус
ollama list

# Перезапустите сервис
# Windows: Перезапустите Ollama из трея
```

### Claude недоступен

```bash
# Проверьте ключ API в .env
# Переключитесь на локальный режим:
AGENT_MODE=local_only
```

### Голосовой ввод не работает

- Убедитесь, что используете Chrome/Edge
- Разрешите доступ к микрофону
- Проверьте язык системы (должен быть русский)
